<objective>
Execute the tutorial end to end on the extracted deposit (D-14) — the one-time
LUT generation, the pipeline run, and the visualization step — timing each stage
to produce the second hardware data point D-15 needs, recomputing the statistics
D-12 turns into tolerance ranges, and correcting anything the run proves wrong in
both the deposit tree and its generating templates.

This is what makes ROADMAP success criterion 3 actually true rather than
plausible. It runs **before** Plans 06 and 07 publish the deposit, so a defect
this run exposes can still be fixed before the record is frozen under a permanent
DOI.

Purpose: DOCS-07 — the tutorial's expected results at each step must be measured,
not asserted.
Output: measured timings and statistics recorded in the plan SUMMARY, any
template/tree corrections the run exposed, and a deposit tree restored to a
shippable 22-file state.
</objective>
