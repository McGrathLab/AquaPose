## Decisions Made

- **`engine.config.ReidConfig` re-verification:** `ReidConfig` (`src/aquapose/engine/config.py:378-400`) is itself `@dataclass(frozen=True)`, same shape as `_EmbedderConfig`. Grepped the repo for any direct `FishEmbedder(ReidConfig(...))` construction: none exists today (the only direct `FishEmbedder(...)` call sites are `reid_training.py:197` via `_EmbedderConfig`, `swap_detector.py:365` via a local anonymous class with plain class-level attributes, and `runner.py:235` via `self._config`, whose declared type was not part of this plan's file scope). Confirmed no code path anywhere assigns to any of the five `ReidConfigLike` members through a protocol-typed reference (`grep` for `config\.(model_name|batch_size|crop_size|device|embedding_dim)\s*=` across `embedder.py`, `reid_training.py`, `runner.py`, `swap_detector.py` returned nothing) — the read-only conversion is safe for every implementer, and since a read-only property is satisfied by any attribute (writable or not) that is readable and of the right type, `ReidConfig` was never at risk from this change regardless.
- Exact text of the two inline suppression reasons (identical at both sites): *"pytorch_metric_learning's MultiSimilarityLoss.__init__ has no type annotations at all; basedpyright infers `int` for alpha/beta purely from the integer default values (alpha=2, beta=50), even though the library documents them as float hyperparameters. This is a third-party inference artifact, not a defect on our side."*
- This is the phase's **entire** suppression budget: 2 directives, both in `reid_training.py`, both attributable to this one untyped constructor. Verified against a measured baseline (71 directives repo-wide before this plan) rather than assumed.
