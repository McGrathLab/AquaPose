## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo metadata → PyPI | `pyproject.toml`'s `version` becomes an immutable filename component on PyPI once uploaded. A wrong value cannot be replaced, only superseded. |
| repo metadata → Zenodo archive | `CITATION.cff` is read by Zenodo's GitHub-release integration and frozen into a permanent, publicly resolvable DOI record. |
| repo metadata → downstream citers | Whatever `CITATION.cff` says is what researchers copy into their papers; a wrong identifier propagates into the literature and is not retractable. |
