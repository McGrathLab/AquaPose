### `src/aquapose/training/prep.py::_parse_keypoints_yolo` (utility, file-I/O/transform)

**Current implementation (lines 62-94)** — parses normalized coords directly, never
scaled to pixels (the bug):
```python
def _parse_keypoints_yolo(
    labels_dir: Path, n_keypoints: int
) -> list[list[tuple[float, float]]]:
    """Parse keypoint instances from a directory of YOLO label txt files. ..."""
    txt_files = sorted(labels_dir.rglob("*.txt"))
    instances: list[list[tuple[float, float]]] = []
    for txt_path in txt_files:
        for line in txt_path.read_text().splitlines():
            parts = line.strip().split()
            if len(parts) < 5 + n_keypoints * 3:
                continue
            kp_values = parts[5:]
            points: list[tuple[float, float]] = []
            for k in range(n_keypoints):
                base = k * 3
                x, y, v = (
                    float(kp_values[base]),
                    float(kp_values[base + 1]),
                    float(kp_values[base + 2]),
                )
                if v > 0:
                    points.append((x, y))          # <-- still normalized [0,1]
                else:
                    points.append((float("nan"), float("nan")))
            instances.append(points)
    return instances
```

**Analog 2 — pixel-space sibling, already correct (`prep.py:31-58`, `_parse_keypoints_coco`)**:
```python
def _parse_keypoints_coco(
    annotations_path: Path, n_keypoints: int
) -> list[list[tuple[float, float]]]:
    """Parse keypoint instances from a COCO JSON file. ..."""
    with annotations_path.open() as fh:
        coco = json.load(fh)

    instances: list[list[tuple[float, float]]] = []
    for ann in coco.get("annotations", []):
        raw_kps = ann.get("keypoints")
        if not raw_kps:
            continue
        points: list[tuple[float, float]] = []
        for k in range(n_keypoints):
            base = k * 3
            if base + 2 >= len(raw_kps):
                break
            x, y, v = raw_kps[base], raw_kps[base + 1], raw_kps[base + 2]
            if v > 0:
                points.append((float(x), float(y)))   # already absolute pixels
            else:
                points.append((float("nan"), float("nan")))
        instances.append(points)
    return instances
```
This is the target shape: `_parse_keypoints_yolo` must emit `(x * img_w, y * img_h)`
tuples with the same NaN-for-invisible convention, so `_compute_t_values` (97-142,
unaffected) continues to consume both paths identically.

```python
def _merge_stage_config(
    defaults: dict[str, Any], overrides: dict[str, Any]
) -> dict[str, Any]:
```

```python
    def __post_init__(self) -> None:
        # Frozen dataclasses forbid normal assignment in __post_init__, but
        # dict is mutable so we just ensure we got a dict (not None).
        if not isinstance(self.extra, dict):
            object.__setattr__(self, "extra", dict(self.extra))
        # Validate detector_kind — only "yolo" and "yolo_obb" are supported.
```

be > 0"` so the terminal gate's message assertion still passes for both the "SET_ME"
