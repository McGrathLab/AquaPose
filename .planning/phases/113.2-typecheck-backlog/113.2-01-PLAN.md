<design_decisions>
These resolve the three items CONTEXT explicitly left to Claude's discretion. Later plans in
this phase depend on them, so they are fixed here rather than re-litigated per file.

**Module:** `src/aquapose/core/h5.py`. Under `core/`, therefore importable by `core/`,
`evaluation/` and `training/` alike (D-04). It imports only `h5py` (third-party) and stdlib,
so `tests/unit/core/test_import_boundary.py` picks it up via `rglob` and passes with no
allowlist entry.

**API:** two functions, both taking an `h5py.Group` (which `h5py.File` subclasses, so a
`File` is accepted without a union parameter) and a key that may contain `/` separators,
since h5py resolves paths natively — `require_dataset(pre, "midlines/fish_id")` works:

- `require_group(parent, key) -> h5py.Group`
- `require_dataset(parent, key) -> h5py.Dataset`

**Return types stop at `h5py.Dataset`, deliberately.** The helper does not return an array
type. h5py ships no `py.typed` marker (verified: `py.typed: False`, h5py 3.16.0), so
basedpyright infers `Dataset.__getitem__` from library source under the default
`useLibraryCodeForTypes`. Declaring an array return would be inventing a dtype the library
does not promise — a cast wearing a helper's clothes. Call sites keep their existing
subscript (`require_dataset(f, "midlines/points")[:]`), so the narrowing is honest and the
diff at each site is one wrapper call.

**Runtime-checked, not `assert`.** Per D-03 the helper raises a real exception, because
`assert` is stripped under `python -O`. The message names both the key and the file so a
malformed H5 fails legibly at the read rather than confusingly three frames later.

**Existing `cast()` sites are left alone.** `core/stitching.py` and `core/reid/swap_detector.py`
already use `cast(h5py.Group, ...)` / `cast(h5py.Dataset, ...)` at read sites that
typecheck cleanly today (`stitching.py:78-84,361-362,705-706`;
`swap_detector.py:289-292,799-800`). Converting them would add a runtime raise path where
none exists, which is a behavior change and therefore forbidden by D-06. This phase converts
**error sites only**. The resulting two-idiom inconsistency — the clean-looking idiom being
the unchecked one — is a real finding and is written up as a follow-up todo in
`113.2-06-PLAN.md` rather than silently absorbed. Converting a `cast()` that sits inside the
same `with h5py.File(...)` block as an error site is permitted for block coherence, but any
such conversion must be listed in the plan SUMMARY as behavior-adjacent.
</design_decisions>
