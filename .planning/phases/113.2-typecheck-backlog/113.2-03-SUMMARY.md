## Decisions Made

- **Narrowing form:** the plain membership test (`if mode not in ("seeded", "scan")`) was
  sufficient for basedpyright's narrowing — no explicit `==` comparison chain was needed. This
  is the simpler of the two forms the plan anticipated and is recorded per the plan's
  instruction to note which form was accepted.
- **Accumulator independence:** verified by reading the full function body — the
  `if not self._spline_enabled:` branch (containing the first `cam_errs`) ends in a `return
  Midline3D(...)` before the `# --- Spline-enabled mode ---` comment and the second `cam_errs`
  declaration. The two blocks can never execute in the same call, so there is no aliasing bug
  masked by the duplicate annotation — this was a pure lint-level duplication, not a
  behavioral finding.
- **TypedDict placement:** defined once in `evaluation/stages/reconstruction.py` (not
  duplicated in `runner.py`) per the plan's single-definition requirement. `runner.py`'s dict
  literal at its construction site structurally satisfies the TypedDict without an explicit
  import, since pyright checks literal dict expressions against the TypedDict shape used as
  the parameter's declared type.
