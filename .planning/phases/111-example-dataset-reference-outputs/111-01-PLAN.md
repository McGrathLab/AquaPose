## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local staging dir -> deposit tree | Source assets (videos, models, live config with absolute paths + machine username) cross into a tree destined for public DOI |
| deposit tree -> public Zenodo DOI | Everything in the deposit becomes irreversibly public (Plan 03 uploads) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-111-01 | Information Disclosure | deposit config.yaml | mitigate | Author a FRESH config with only relative paths (D-07); never copy the live YH config (has `/home/tlancaster6/...` absolute paths + username). Unit test asserts no `/home/` or `D:\` substring. |
| T-111-02 | Information Disclosure | deposit videos/ | mitigate | Temporal trim to 30s of a documented segment; strip audio (`-an`). No PII in fish-tank footage; the Task-3 human checkpoint visually confirms content before any public upload. |

| T-111-SC | Tampering | pip/package installs | accept | No new package installs in this plan — stdlib + existing `yaml`/`aquapose` only. No RESEARCH.md package audit needed. |
