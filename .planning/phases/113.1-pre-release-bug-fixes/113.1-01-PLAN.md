prove them with the two non-negotiable terminal gates.

key, a config that already carries `pose.keypoint_t_values` silently discards
whatever the corrected arc-length code computes — so an arc-length fix landed
first cannot be observed. Task 1 therefore lands the writer fix and the
arc-length fix as one end-to-end slice, writer edit first, verified by a single
assertion that only passes if BOTH are correct.

Purpose: QA-05 success criteria 1 and 2, and the pair of correctness bugs that
block the deferred `113-06-PLAN.md` DOI mint.
Output: a `calibrate-keypoints` that writes unbiased t-values to the canonical
`pose:` key, and a test file whose assertions cannot pass on the old code.
</objective>
