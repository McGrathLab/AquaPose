<objective>
Pass B of the two-pass DOI sequence (D-11): now that the release exists and Zenodo has
minted the software DOIs, backfill the **concept** DOI into `CITATION.cff` and add the
seventh and final badge — the Zenodo DOI — to the README badge row.

This is the last plan in the phase, and it is the one that closes the circularity D-11
identified: Zenodo mints only after the release publishes, but the release snapshot is
what Zenodo reads metadata from. The accepted consequence is that the `v4.0.0` tagged
tree does not itself carry the DOI. That is a one-time cost — the concept DOI never
changes again, and every future release inherits it.

Purpose: completes README-02 (the full seven-badge row) and README-04 (a citation
surface carrying a real, resolvable software DOI).
